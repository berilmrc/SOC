# SoC Tahmini ve Hücre Dengeleme

> 🚧 Bu proje hazırlanıyor, içerik yakında eklenecek.

**Kategori:** Okul · BAP (Bilimsel Araştırma Projesi)

## Proje hakkında

Batarya hücrelerinin şarj durumunu (SoC) izleyen ve hücreleri aktif olarak dengeleyen bir sistem üzerine çalışma.

## Klasörler

- `simulasyon/`: MATLAB/Simulink modelleri (hücre modeli, dengeleme kontrolcüsü, PWM anahtarlama)
- `arayuz/`: Python seri port arayüzü
- `bap-belgeleri/`: proje önerisi, teknik şartname, bütçe
- `literatur/`: literatür araştırması
- `gorseller/`: grafikler ve şemalar
